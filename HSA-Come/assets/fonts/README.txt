Cairo Font Files — HSA Come
============================

AR (العربية):
قم بتحميل خط Cairo (مرخص تحت SIL Open Font License 1.1) من مستودع Google Fonts الرسمي على GitHub:
  المستودع: google/fonts
  المجلد: ofl/cairo
ثم ضع الملفات التالية في هذا المجلد:
  - Cairo-Regular.woff2
  - Cairo-SemiBold.woff2
  - Cairo-Bold.woff2
  - Cairo-Black.woff2
(اختياري: ملفات .woff بديلة)

EN:
Download the Cairo font (SIL Open Font License 1.1) from the official Google Fonts GitHub repo:
  Repo: google/fonts
  Folder: ofl/cairo
Then place these files in this folder:
  - Cairo-Regular.woff2
  - Cairo-SemiBold.woff2
  - Cairo-Bold.woff2
  - Cairo-Black.woff2
(Optional: .woff alternates)

Note: The CSS @font-face rules in css/themes.css already point to these filenames.
Until the files are added, the site gracefully falls back to system fonts.
ملاحظة: قواعد @font-face في css/themes.css تشير بالفعل إلى هذه الأسماء.
حتى إضافة الملفات، يعمل الموقع بخطوط النظام كبديل أنيق.
